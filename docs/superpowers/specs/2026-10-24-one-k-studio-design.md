# ONE K Studio — التصميم
**التاريخ:** 2026-10-24  
**الحالة:** الاتجاه معتمد من إيسكو  
**المستودع:** gmloj/one-k-auto

## الهدف
تحويل صفحة ONE K إلى تجربة عرض سينمائية فاخرة تشرح العناية بالسيارة من خلال سيارة كوبيه رياضية بلا شعار، وتحوّل الاهتمام إلى استفسار عبر واتساب.

## الاتجاه
- الحفاظ على هوية ONE K الداكنة والبرتقالية، مع إبراز الشعار الحالي عند توفر ملفه الأصلي.
- سيارة رياضية عامة بلا شعار علامة تجارية، تُعرض في استوديو داكن بإضاءة برتقالية وانعكاسات مدروسة.
- السيارة هي محور القصة: الزجاج، الطلاء، الشمعات، أطراف الأبواب، المقاعد، والدعسات؛ كل اختيار يحرّك الكاميرا إلى موضعه ويعرض شرحًا صادقًا.
- أقسام الخدمات تُعرض كمشاهد مختلفة (الخارجية، التفاصيل الدقيقة، المقصورة)، لا تكرار شبكات البطاقات.
- جوال أولًا: مشهد سيارة قابل للاستخدام، شريط خدمات أفقي، زر حجز واضح، ونص مقروء.
- إضاءة/حركة عبر CSS وThree.js القائمين؛ لا تشغيل صوت أو فيديو تلقائي.
- تنزيل المجسم على مراحل/تأجيل تحميله مع صورة تمهيدية، ضغط الأصول، fallback عند فشل WebGL، ودعم prefers-reduced-motion.
- لا أسعار أو ضمانات أو إحصاءات أو شهادات غير مؤكدة؛ تبقى الدعوة للحجز عبر رقم واتساب الحالي.

## بدائل مرفوضة
- فيديو كامل كخلفية: يستهلك البيانات، لا يتيح التفاعل الحقيقي، ولا يناسب الجوال.
- استبدال الصفحة بقالب متجر: يضعف فكرة الاستكشاف بالمجسم ويحوّل الهوية إلى واجهة عامة.

## النطاق
تحديث `index.html` و`dist/index.html` ومجلد `assets/`، مع إبقاء مسار GitHub Pages وروابط واتساب الحالية. اختيار أصول 3D لا يتم إلا بعد التحقق من إمكان الاستخدام وإثبات الترخيص في `assets/MODEL-LICENSE.md`.
