# تجربة السيارة السينمائية — خطة التنفيذ

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ترقية تجربة ONE K التفاعلية إلى سيارة رياضية 3D واقعية قابلة للدوران، مع لقطتي اقتراب للعازل الحراري وPPF وزر رجوع.

**Architecture:** إبقاء صفحة الهبوط الحالية ومشهد Three.js. تحميل مجسّم GLB محلي مرخّص عبر GLTFLoader مع الاحتفاظ بالمجسم الحالي كخطة بديلة، وربط اختيار الخدمة بحركة كاميرا وإضاءة ولوحة معلومات.

**Tech Stack:** HTML/CSS/JavaScript، Three.js 0.164.1، GLTFLoader، GitHub Pages ونسخة `dist` الحالية.

**Spec:** `docs/superpowers/specs/2026-10-23-one-k-cinematic-car-experience-design.md`

## Global Constraints

- مجسّم 3D واضح وواقعي بطابع رياضي فاخر، من دون شعار أو ادعاء أنه سيارة بورش أصلية.
- عند اختيار الزجاج: انتقال كاميرا ناعم إلى الزجاج، إبراز بصري للعازل الحراري، ولوحة تفاصيل الخدمة.
- عند اختيار الهيكل: انتقال إلى الطلاء، إبراز طبقة PPF، ولوحة تفاصيل الخدمة.
- زر رجوع يعيد زاوية السيارة والمشهد الأصليين.
- دعم دوران السيارة بالسحب، والنقر بالماوس واللمس.
- المحافظة على هوية ONE K الداكنة والبرتقالية، محتوى العربية، وروابط الحجز الحالية عبر واتساب.
- تجربة قابلة للاستخدام على الجوال، مع تخفيف المجسّم واحترام إعداد تقليل الحركة.
- تضمين الأصل محليًا بعد التحقق من ترخيصه، وتحديث نسختي `index.html` في الجذر و`dist/index.html`.

## Review Focus

- فشل تحميل GLB أو عدم توفر WebGL: إظهار السيارة الاحتياطية واستمرار إمكانية الوصول للخدمات.
- اختيار خدمة ثم الرجوع أو اختيار خدمة ثانية: إعادة الكاميرا والإضاءة واللوحة للحالة الصحيحة.
- شاشة جوال أو لمسات متتابعة: بقاء نقاط الاختيار قابلة للضغط من دون تداخل اللوحة.
- تفضيل تقليل الحركة: إتمام انتقالات قصيرة بلا حركة كاميرا مستمرة أو تأثيرات وامضة.
- أصل 3D كبير أو بطيء: إبقاء حجم التحميل معقولًا وظهور البديل حتى يجهز الأصل.

### Task 1: إضافة مجسّم 3D مرخّص

**Files:**
- Create: `assets/one-k-coupe.glb`
- Create: `assets/MODEL-LICENSE.md`

**Interfaces:**
- Produces: مجسّم GLB محلي لسيارة كوبيه رياضية بلا شعارات، ومحاورها واتجاه مقدمتها موثقان في ملف الترخيص.

- [ ] **Step 1: اختيار أصل GLB وإثبات ترخيصه التجاري**
  دوّن رابط المصدر، صاحب الأصل، نوع الترخيص، وشروط النسبة المطلوبة في `assets/MODEL-LICENSE.md`. لا تُدرج أصلًا يمنع الاستخدام التجاري أو لا يوضح ترخيصه.

- [ ] **Step 2: إضافة الأصل محليًا والتحقق من سلامة الملف**
  تأكد أن الملف يبدأ بتوقيع GLB `glTF` وأن حجمه مناسب للتحميل على الجوال. إذا تعذر إيجاد أصل مناسب أو كان حجمه غير معقول، أوقف هذه المهمة وأعد تقييم الخطة قبل المتابعة.

- [ ] **Step 3: حفظ الملفات والتحقق منها على GitHub**
  تحقق أن ملف GLB موجود في المستودع ويمكن جلبه، وأن وثيقة الترخيص تطابق المصدر والترخيص الفعلي.

### Task 2: ربط المجسّم بتجربة الاختيار السينمائية

**Files:**
- Modify: `index.html` (مشهد الهبوط ومكوّنات CSS/JavaScript الحالية)
- Modify: `dist/index.html` (نسخة النشر الثابتة المطابقة)
- Uses: `assets/one-k-coupe.glb` و`assets/MODEL-LICENSE.md`

**Interfaces:**
- Consumes: GLB محلي واتجاه السيارة الموثق في Task 1.
- Produces: عناصر اختيار `film` و`ppf`، دالة اختيار خدمة تحرك الكاميرا نحو الزجاج أو الطلاء، ودالة رجوع تعيد وضع البداية؛ لوحة التفاصيل الحالية تستمر باستخدام روابط واتساب نفسها.

- [ ] **Step 1: ربط GLTFLoader وتحميل GLB**
  حمّل `assets/one-k-coupe.glb`، وسوِّ حجمه وموضعه ضمن المشهد، وأظهر المجسم الحالي كـ fallback إلى أن يكتمل التحميل أو عند حدوث خطأ.

- [ ] **Step 2: ربط مناطق الزجاج والطلاء**
  أضف أهدافًا تفاعلية مناسبة للمؤشر واللمس ولوحة المفاتيح. تحقّق أن كل هدف يفتح نوع الخدمة المقابل فقط، وأن اللوحة تعرض نص الخدمة الموجود حاليًا.

- [ ] **Step 3: تنفيذ انتقالات الكاميرا والرجوع**
  عند `film` قرّب إلى الزجاج وأبرز إضاءته؛ عند `ppf` قرّب إلى الطلاء وأبرز طبقته؛ وعند الرجوع أعد زاوية الكاميرا والإضاءة وأخفِ اللوحة.

- [ ] **Step 4: دعم تقليل الحركة والجوال**
  احترم `prefers-reduced-motion`، وخفّض دقة الرسم على الجوال، واضبط مواضع الأهداف واللوحة كي تظل قابلة للاستخدام.

- [ ] **Step 5: اختبر الواجهة مباشرة بعد النشر**
  على GitHub Pages، اختبر بالترتيب: تحميل GLB، تدوير السيارة، العازل، رجوع، PPF، رجوع، ثم زري الخدمة على الهاتف. اختبر كذلك fallback عند تعطيل WebGL، وراجع نصوص العربية وروابط واتساب.

- [ ] **Step 6: مزامنة نسخة `dist` والتحقق من تطابقها**
  قارن ملفي HTML للتأكد أن التجربة واحدة على جذر GitHub Pages ومسار `dist`، ثم راجع آخر commit وحالة النشر.
